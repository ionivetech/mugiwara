# Example mission trail

What a finished mission looks like — generated by the real pipeline
(`savepoint.sh` → `mugiwara archive`) on a scratch repo, not written by hand.
The wave prose is illustrative; every artifact SHAPE here is what closure
actually produces.

| File | What it is |
|------|------------|
| [`invite-user/plan.md`](invite-user/plan.md) | The plan — survives archive untouched |
| [`invite-user/report.md`](invite-user/report.md) | Closure summary + folded waves + review routing + context footprint |
| [`invite-user/provenance.md`](invite-user/provenance.md) | PR-paste-ready attribution (paste into the PR description) |
| [`invite-user/rollback.sh`](invite-user/rollback.sh) | Executable revert map (newest-first), human-run only |

Read `report.md` first: that single file is what a reviewer gets after any
mission on your repo.
